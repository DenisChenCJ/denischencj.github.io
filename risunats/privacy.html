歡迎使用 Risunats - 閱讀 更舒適（以下簡稱「Risunats」），這是一款 Chrome 擴充功能。本政策說明 Risunats 會處理哪些資料、資料存放在哪裡，以及您如何管理這些資料。

  • Risunats 沒有自己的伺服器，不會把任何資料傳送給開發者或第三方。
  • 您儲存的網頁與設定只存放在您的 Chrome 瀏覽器中；若您開啟 Chrome 同步，會在您自己的裝置之間同步。
  • 不含廣告、分析或追蹤程式，也不販售任何資料。

1. Risunats 會處理的資料

A. 您儲存的網頁

當您在網頁上開啟 Risunats 面板，並標記「未讀」、設定提醒日期或加上標籤時，Risunats 會儲存該網頁的：

  • 網址、標題，以及網站圖示的網址
  • 未讀狀態、提醒日期與所選的標籤
  • 建立與更新的時間

只開啟面板、沒有進行上述操作的網頁不會被儲存。

B. 標籤、Web pin 與字體設定

  • 您建立的標籤名稱
  • 您釘選（Web pin）的網站網域名稱，以及該網站圖示的網址
  • 您選擇的字體大小

C. 目前分頁的資訊

開啟面板時，Risunats 會讀取目前分頁的網址、標題與網站圖示，用來判斷這個網頁是否已經儲存過。若您沒有儲存該網頁，這些資訊不會被保留。

D. 網頁內容

夜間閱讀模式與字體縮放只會在您的瀏覽器中改變網頁的顯示方式。Risunats 不會讀取、儲存或傳送網頁的文字、圖片等內容。

2. 資料存放位置

  • 以上資料儲存在 Chrome 提供給擴充功能的儲存空間（chrome.storage.sync）。
  • 若您在 Chrome 開啟了同步功能，Chrome 會透過您的 Google 帳戶，把這些資料同步到您登入同一帳戶的其他電腦。此同步由 Google 依其隱私權政策處理。
  • 開發者無法存取您的任何資料。

3. 網路連線

Risunats 本身不會連線到開發者或任何第三方的伺服器。只有以下情況會產生連線，且都與一般瀏覽網頁相同：

  • 閱讀清單顯示網站圖示時，瀏覽器會向該網站載入它的圖示。
  • 您點擊擴充功能頁面上的「提供我們建議或想法」或開發者網站連結時，會開啟對應的網頁。

4. 權限用途

  • 分頁（tabs）、activeTab、scripting：讀取目前分頁的網址與標題；在您點擊圖示、使用快捷鍵或右鍵選單時，於該分頁開啟面板。
  • 網站存取（http / https 網頁）：在網頁上顯示面板、套用夜間模式與字體大小，以及在您釘選的網站自動開啟面板。
  • 儲存空間（storage）：保存您的閱讀清單與設定。
  • 鬧鐘（alarms）與通知（notifications）：每 3 小時檢查一次提醒日期，到期時通知您。
  • 右鍵選單（contextMenus）：提供開啟面板與閱讀清單的選項。
  • offscreen：播放提醒音效。

5. 您的控制權

  • 在面板中隨時取消「未讀」或提醒日期。
  • 在設定頁刪除標籤與 Web pin。
  • 移除 Risunats 擴充功能時，Chrome 會刪除它儲存的資料。若您使用 Chrome 同步，也可以到 Chrome 同步資料管理頁面清除已同步的資料。

6. 政策變更

若本政策有所變更，我們會更新本頁內容並修改上方的「最近更新日期」。

7. 聯絡我們

若您對本隱私權政策有任何疑問或建議，歡迎透過意見表單或電子郵件 gtr6gb836@gmail.com 與開發者聯繫。

Privacy Policy

Last updated: October 21, 2026

This policy explains what data Risunats - Read with cozy way ("Risunats"), a Chrome extension, handles, where the data is stored, and how you can manage it.

  • Risunats has no server of its own and never sends any data to the developer or to third parties.
  • The pages and settings you save are stored only in your Chrome browser. If Chrome sync is on, they are synced between your own devices.
  • No ads, analytics or tracking code. No data is sold.

1. Data Risunats handles

A. Pages you save

When you open the Risunats panel on a web page and mark it as unread, set a reminder date or add a label, Risunats stores for that page:

  • its URL, title and the URL of the site's icon
  • the unread status, reminder date and selected labels
  • the time it was created and last updated

Pages where you only open the panel, without doing any of the above, are not stored.

B. Labels, Web pins and font settings

  • the names of the labels you create
  • the domain names of sites you pin (Web pin), and the URL of each site's icon
  • your chosen font size

C. Current tab information

When you open the panel, Risunats reads the current tab's URL, title and icon to check whether the page has already been saved. If you don't save the page, this information is not kept.

D. Page content

The dark reading mode and font size adjustment only change how the page is displayed in your browser. Risunats does not read, store or transmit the text, images or other content of web pages.

2. Where the data is stored

  • All of the data above is stored in the extension storage provided by Chrome (chrome.storage.sync).
  • If Chrome sync is turned on, Chrome syncs this data through your Google Account to your other computers signed in to the same account. This sync is handled by Google under its Privacy Policy.
  • The developer cannot access any of your data.

3. Network connections

Risunats itself does not connect to any server of the developer or of third parties. The only connections happen in these cases, the same as normal browsing:

  • When the reading list shows a site's icon, the browser loads that icon from the site.
  • When you click the feedback link or the developer's website link in the extension pages, the corresponding web page opens.

4. How permissions are used

  • tabs, activeTab, scripting: read the current tab's URL and title, and open the panel in that tab when you click the toolbar icon, press the keyboard shortcut or use the context menu.
  • Site access (http / https pages): show the panel on the page, apply the dark reading mode and font size, and open the panel automatically on sites you have pinned.
  • storage: keep your reading list and settings.
  • alarms and notifications: check reminder dates every 3 hours and notify you when a reminder is due.
  • contextMenus: add right-click menu items to open the panel and the reading list.
  • offscreen: play the reminder sound.

5. Your choices

  • Turn off "Unread" or a reminder date in the panel at any time.
  • Delete labels and Web pins on the settings page.
  • When you remove the Risunats extension, Chrome deletes the data it stored. If you use Chrome sync, you can also clear synced data on the Chrome sync data page.

6. Changes to this policy

If this policy changes, we will update this page and the "Last updated" date above.

7. Contact
